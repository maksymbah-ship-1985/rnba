# RNBA Email Sender

WordPress плагін для масової розсилки email-повідомлень клієнтам WooCommerce, які придбали певні товари.

## Можливості

- Пошук клієнтів за ID товарів WooCommerce
- Фільтрація тільки оплачених замовлень (статус `completed`)
- Система шаблонів листів з підтримкою плейсхолдерів
- Тестова відправка перед масовою розсилкою
- Детальний лог відправки в реальному часі
- Інтеграція з WP Mail SMTP

## Вимоги

- WordPress 5.0+
- WooCommerce 5.0+
- PHP 7.4+
- Налаштований WP Mail SMTP (рекомендовано)

## Встановлення

1. Завантажте папку `rnba-email-sender` у `/wp-content/plugins/`
2. Активуйте плагін у розділі "Плагіни" WordPress
3. Перейдіть до меню **RNBA Розсилка** в адмін-панелі

## Використання

### Основний процес

1. **Введіть ID товарів** — через кому (наприклад: `123, 456, 789`)
2. **Виберіть шаблон** — зі списку доступних шаблонів
3. **Введіть тему листа** — тема для email
4. **Знайдіть клієнтів** — натисніть кнопку для пошуку
5. **Перевірте список** — переконайтесь, що знайдені правильні клієнти
6. **Надішліть тест** — спочатку відправте на свій email
7. **Запустіть розсилку** — відправте всім клієнтам

### URL адмін-сторінки

```
/wp-admin/admin.php?page=rnba-forum-email-notifier
```

## Шаблони листів

### Розташування

Шаблони зберігаються у папці:
```
rnba-email-sender/templates/
```

### Створення нового шаблону

1. Створіть HTML-файл у папці `templates/`
2. Назва файлу стане назвою шаблону (наприклад: `forum-reminder.html` → "Forum Reminder")
3. Шаблон автоматично з'явиться у списку вибору

### Доступні плейсхолдери

| Плейсхолдер | Опис |
|-------------|------|
| `{{first_name}}` | Ім'я клієнта |
| `{{last_name}}` | Прізвище клієнта |
| `{{email}}` | Email клієнта |

### Приклад використання плейсхолдерів

```html
<p>Добрий день, {{first_name}}!</p>
<p>Дякуємо за вашу покупку...</p>
```

> **Примітка:** Якщо плейсхолдери не використовуються — лист відправиться без замін.

- AJAX nonce верифікація

- Prepared statements для SQL-запитів

## Технічні деталі

### Запит клієнтів

Плагін шукає клієнтів через прямий SQL-запит до таблиць WooCommerce:
- `wp_posts` — замовлення
- `wp_woocommerce_order_items` — товари в замовленні
- `wp_woocommerce_order_itemmeta` — метадані товарів
- `wp_postmeta` — email та ім'я клієнта

Фільтри:
- Тип запису: `shop_order`
- Статус: `wc-completed`
- Тип позиції: `line_item`

### Відправка пошти

Використовується стандартна функція `wp_mail()`, яка автоматично інтегрується з WP Mail SMTP та іншими плагінами для відправки пошти.
